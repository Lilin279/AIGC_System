# 管理员指南

## 教师审核

进入“用户与审核”，核对姓名、院系、职称和邮箱。通过后教师立即获得开课权限；驳回必须填写原因，教师可在审核状态页查看原因。

## 学生批量导入

1. 在教师或管理员班级页面选择教学班。
2. 上传 CSV/XLSX，使用学号、姓名、班级、邮箱、手机号列。
3. 查看预检中的有效行、错误行与原因。
4. 确认导入后立即保存临时账号结果；临时密码只返回一次。
5. 重复学号更新资料并补充班级关系，不重置已有密码。

## 工单与审计

管理员可查看全校工单，分派给自己并切换待处理、处理中、等待用户、已解决、已关闭状态。普通用户只可查看本人提交的工单。教师审核、学生导入、图谱版本、课件删除和工单状态变更均写入审计日志。

## 数据处理原则

存在课程、班级或工单关联的账号优先禁用，不建议物理删除。课程停止使用时改为归档。执行批量操作前先导出数据库卷备份。
