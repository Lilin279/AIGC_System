## 2. 产品定位

CourseGraph AI 面向高校和职业院校，帮助教师将课程课件转换为可审核、可追溯的知识图谱，并通过教学班把正式图谱、学习路径、课程问答和练习服务提供给指定学生。

核心价值：

- 降低教师人工梳理课程知识点和关系的成本。
- 将课程内容、教学班和学生学习进度分层管理。
- 通过候选版本审核和来源引用控制 AIGC 错误风险。
- 基于课件证据和图谱关系提供可追溯问答。
- 根据学生掌握状态生成确定性学习路径与 AI 解释。

当前产品适合比赛演示、单学校试点和小规模教学验证，尚未达到面向多学校、高并发和强合规场景的生产标准。

## 3. 用户与权限

### 3.1 学生

- 自助注册后直接激活。
- 通过班级码或教师批量导入加入教学班。
- 只能查看自己已加入且处于开课状态的班级。
- 学习进度按“学生 + 教学班 + 知识点”隔离。
- 可浏览图谱、标记掌握、查看学习路径、生成练习和进行可溯源问答。
- 可修改个人资料、头像和密码，提交并查看自己的反馈工单。

### 3.2 教师

- 提交注册申请后进入待审核状态。
- 未审核教师只能查看审核状态、个人中心和反馈工单。
- 审核通过后可创建课程、开设教学班、管理成员和课程内容。
- 上传课件后生成候选图谱，确认前不会影响学生看到的正式图谱。
- 可编辑知识点和关系、审核候选版本、恢复历史版本。
- 删除课件时可预览影响并选择是否同步回滚图谱来源。

### 3.3 管理员

- 使用独立管理员控制台。
- 可查看全校用户、课程、班级、工单和审计日志。
- 可审核、驳回和禁用教师账号。
- 可调整用户资料、班级主教师和成员关系。
- 支持 CSV/XLSX 学生导入预检与确认。
- 可分派工单并推动工单状态流转。

## 4. 核心业务模型

系统采用三层业务结构：

```text
Course 课程内容
  ├─ 课件与文档分片
  ├─ 正式知识图谱
  ├─ 候选图谱和历史版本
  └─ 来源、质量和审计记录

Classroom 教学班
  ├─ 学期与开课状态
  ├─ 主教师和协作教师
  ├─ 班级码
  └─ 学生名单

Enrollment 学习关系
  ├─ 学生入班关系
  ├─ 按班级隔离的掌握状态
  ├─ 学习路径
  └─ 诊断、问答与练习
```

课程不等于教学班。一门课程可在不同学期、不同班级复用；学生访问的是教学班关联的已确认课程内容。

## 5. 已实现功能

### 5.1 账号与学校管理

- 登录、退出和七天会话。
- PBKDF2-SHA256 密码哈希。
- 学生注册、教师申请和管理员审核。
- 账号启用、禁用和关键身份字段权限控制。
- 个人资料、头像和修改密码。
- 批量导入账号首次登录强制改密。

### 5.2 课程与课件

- 课程创建、修改、发布、归档和权限校验。
- 支持 PDF、DOCX、PPTX、TXT、Markdown。
- 单课件限制 20 MB。
- 文档分片保存课程、文档、页码和原文。
- 解析后创建持久化抽取任务，可查看任务进度和失败原因。

### 5.3 图谱生命周期

- 知识点和关系增删改。
- 三种基础关系：包含、前置、相关。
- DeepSeek 抽取结果先进入候选版本。
- 候选图谱确认、驳回、版本列表和历史恢复。
- 节点、关系与课件来源关联。
- 删除课件前影响预览和选择性回滚。
- 图谱质量评分：重复率、孤立率、关系覆盖率和来源覆盖率。

### 5.4 教学班与学习

- 教学班创建、修改、开课状态和班级码重置。
- 主教师、协作教师和学生成员管理。
- CSV/XLSX 导入预检、错误行反馈、确认导入和临时密码一次性展示。
- 学生课程可见性和跨班学习进度隔离。
- 基于前置关系和掌握状态的确定性学习路径。
- AI 个性化诊断、针对性讲解和基础题、应用题、易错题。

### 5.5 GraphRAG

- SQLite FTS5 全文索引。
- 中文 2-gram / 3-gram 检索词生成。
- BM25 课件片段排序。
- 知识点匹配和图谱邻居扩展。
- DeepSeek 仅基于检索证据回答。
- 返回课件名称、页码、引用片段、知识点和置信提示。
- 证据不足时拒答；未配置 AI 时明确标记离线模式。

### 5.6 客户服务与审计

- 用户反馈工单、紧急程度、附件和回复。
- 工单状态：待处理、处理中、等待用户、已解决、已关闭。
- 普通用户只能查看本人工单。
- 管理员分派和状态修改。
- 站内通知和关键操作审计日志。

## 6. 技术架构

| 层级 | 当前实现 |
|---|---|
| 前端 | React 18、TypeScript、Vite、Lucide Icons |
| 图谱展示 | AntV G6 5.x |
| 后端 | FastAPI、Pydantic、Uvicorn |
| 主数据库 | SQLite |
| 检索 | SQLite FTS5、BM25、中文 N-gram |
| 大模型 | DeepSeek OpenAI 兼容接口，默认 `deepseek-v4-flash` |
| 文档解析 | pypdf、OOXML 解析；OCR 可选 PyMuPDF + RapidOCR |
| 图数据库 | Neo4j Community/AuraDB；正式图谱同步、一致性校验、学习路径与 GraphRAG 图查询 |
| 部署 | 本地启动、Docker Compose、Nginx 前端容器 |

### 6.1 SQLite 与 Neo4j 的当前边界

SQLite 是当前唯一的主数据源，保存账号、课程、教学班、课件、图谱、版本、来源、学习记录、工单和审计数据。

Neo4j 已从“可选同步副本”升级为正式图查询通道：

- 未配置 Neo4j 时，系统全部功能继续使用 SQLite。
- Neo4j 连接失败时自动降级，不影响正式图谱。
- 审核、恢复、手工编辑和课件回滚后自动同步；支持单课程手动同步和管理员全量同步。
- 同步后核对节点数、关系数和图谱版本；失败状态持久化，服务重启时自动补偿。
- 学习路径从 Neo4j 查询前置关系；GraphRAG 使用 Neo4j 一至两跳邻居作为独立召回通道。
- 查询或同步异常时回退 SQLite，并在返回模式和证据来源中明确标记实际通道。

## 9. 标准演示流程

1. 管理员登录，查看学校概览并审核教师。
2. 教师创建课程，上传 PDF/DOCX/PPTX/TXT/Markdown 课件。
3. 系统解析课件并创建 DeepSeek 抽取任务。
4. 教师查看候选图谱、来源和质量提示，确认或驳回版本。
5. 教师创建教学班，通过班级码或批量导入添加学生。
6. 学生进入学习空间，浏览正式图谱并标记掌握状态。
7. 学生生成学习诊断、推荐路径、三类练习并进行可溯源问答。
8. 教师删除错误课件，查看影响范围并执行同步回滚。
9. 管理员查看审计日志并处理反馈工单。

## 11. 已知问题与技术债

### 11.1 图谱渲染风险

- G6 使用力导向布局，节点较多时可能出现初始化时间增加、短暂移动或操作变卡。
- 快速课程切换曾出现旧图谱销毁延迟问题，当前版本保持已验证的渲染实现。
- 在没有专项回归前，不要修改 `GraphView.tsx` 的实例生命周期、销毁逻辑和 force 参数。
- 前端生产包体积较大，G6 导致主 JavaScript 包超过 Vite 默认 500 kB 提示线。

### 11.2 数据和一致性

- SQLite 适合单机和小规模试点，不适合多实例同时写入。
- 抽取任务为持久化状态，但尚未使用独立任务队列和工作进程。
- Neo4j 已具备手动全量同步、差异核验、同步状态账本和启动补偿；后续仍应将补偿迁移到独立任务队列。
- 删除课件和多来源节点已覆盖主要场景，仍需扩大中间版本、人工修订和并发删除测试。

### 11.3 AI 与 RAG

- 当前没有向量 Embedding 和 Reranker，语义表达差异较大的问题可能召回不足。
- 知识融合主要依据规范化名称，尚未完成完整同义词库和实体消歧。
- 大模型可能输出结构正确但语义错误的关系，仍依赖教师审核。
- AI 调用有用量日志，但缺少学校级预算、额度预警和模型熔断管理。

### 11.4 文档解析

- 常规 PDF、DOCX、PPTX 已支持，但复杂排版、公式、图表和表格提取质量有限。
- OCR 是可选依赖，尚未使用真实扫描课件完成页码和坐标验收。
- 上传文件目前主要依据扩展名和大小校验，缺少病毒扫描、内容类型嗅探和对象存储。

### 11.5 账号与安全

- 缺少找回密码、邮箱/短信验证和多因素认证。
- 登录接口尚未加入 IP/账号限流、连续失败锁定和验证码策略。
- 会话固定七天，缺少设备管理、全端退出和管理员强制失效。
- 演示账号和管理员重置演示数据功能不适合公开生产环境。
- CORS 仅配置本地地址；部署时需要显式配置正式域名。

### 11.6 产品体验

- 页面当前使用单文件 `App.tsx` 承载较多业务组件，继续扩展前应拆分路由和领域模块。
- 站内通知已有接口，但缺少完整通知中心、未读数量和实时刷新。
- 管理员资源页以查看和基础修改为主，批量禁用、归档、导出和高级筛选仍需增强。
- 错误提示主要使用顶部通知，缺少字段级错误、空状态操作建议和统一 Toast。
- 移动端可完成主要操作，但图谱编辑和大表格仍建议使用桌面端。

   - 引入路由，将页面、业务 hooks、表单和表格组件按领域拆分。
   - 对 G6 和管理员模块做懒加载。
   - 验收：首屏包体积明显下降，页面模块可独立测试，业务行为不变。

### P2：竞赛创新和效果提升

1. **混合 GraphRAG**
   - 在 BM25 基础上增加中文 Embedding、向量检索和 Reranker。
   - 将 Neo4j 多跳邻居作为独立召回通道。
   - 验收：24 题及扩展测试集的引用正确率、拒答率和召回率均有量化提升。

2. **知识融合与消歧**
   - 建立课程同义词表、实体别名、章节上下文和冲突合并界面。
   - 验收：重复实体率下降，教师可查看并撤销每次融合决定。

3. **个性化学习闭环**
   - 保存练习作答、错题、问答困难点和复习结果。
   - 根据结果动态调整薄弱点、路径优先级和练习难度。
   - 验收：不同学习行为的学生得到可解释、可复现的不同推荐。

4. **教学分析看板**
   - 增加班级知识点热力图、薄弱知识聚类、问题排行和干预记录。
   - 验收：教师能够从班级数据定位薄弱知识点并下发教学任务。

5. **AI 质量和成本治理**
   - 增加提示词版本、模型版本、质量抽样、预算、告警和调用熔断。
   - 验收：每次生成可定位到模型和提示词版本，学校可设置月度额度。

## 14. 交接后的开发规则

1. 开始工作前检查 `dev` 最新提交与工作区状态，不覆盖他人未提交改动。
2. 新页面或组件开发前必须阅读根目录 `design.md`。
3. 不在源码、日志、截图、数据库和 Git 中保存 DeepSeek Key 或 Neo4j 密码。
4. 修改数据库结构时必须通过迁移函数兼容旧数据，不直接删除用户表。
5. 修改图谱渲染前单独建立分支，并回归课程快速切换、单画布数量、节点稳定和移动端尺寸。
6. AI 功能必须保留模式标记、证据、失败降级和可理解错误，不得把 Mock 输出伪装成真实 AI。
7. 每次提交前至少执行：

```powershell
cd D:\AIGC\backend
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v

cd D:\AIGC\frontend
npm.cmd exec tsc -- --noEmit
npm.cmd run build
```

8. 发布前检查 `.env` 未被 Git 跟踪，并备份数据库与上传目录。
