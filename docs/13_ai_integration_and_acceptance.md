# 真实 AI 接入与验收说明

## 实现边界

- 图谱渲染组件未修改；AI 只改变候选图谱数据、回答、讲解和练习内容。
- 学习路径顺序继续由前置关系和掌握状态确定，DeepSeek 仅解释推荐原因。
- 未配置 Key 或调用失败时，界面明确显示离线模式，规则结果不标记为 AI 生成。
- DeepSeek Key 只从根目录 `.env` 或进程环境变量读取，不写入数据库、日志、接口或 Git。

## 真实联调步骤

1. 将 `.env.example` 复制为 `.env`，只填写 `DEEPSEEK_API_KEY`。
2. 重启后端，登录后访问 `GET /api/ai/status`，确认 `configured=true` 和 `mode=deepseek`。
3. 教师上传《第二章 程序语言的基本知识.pdf》，创建抽取任务。
4. 检查候选版本是否不少于 20 个知识点、覆盖三类关系，并抽查页码、原文片段和置信度。
5. 确认候选版本后，以学生身份运行问答、学习诊断和三类练习。
6. 执行问答验收脚本：

```powershell
cd D:\AIGC
backend\.venv\Scripts\python.exe scripts\run-qa-evaluation.py
```

## 数据与指标

`ai_usage_logs` 只记录模型、能力、成功状态、输入/输出 Token 和耗时，不保存提示词正文或课件内容。费用按联调当天 DeepSeek 官方单价计算：

```text
费用 = 输入 Token / 1,000,000 * 当日输入单价
     + 输出 Token / 1,000,000 * 当日输出单价
```

不得在没有真实调用记录时填写准确率、时延或费用。核心验收目标：实体与关系人工准确率不低于 70%，单章抽取不超过 60 秒，问答不超过 15 秒。

## 人工标注

原 PDF 当前不纳入 Git。重新上传后，两位组员分别使用 `sample_data/evaluation/extraction-gold-template.csv` 标注实体、关系、页码和原文，分歧由第三人复核。建议至少标注 20 个实体和 20 条关系。
