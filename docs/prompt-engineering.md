# 提示词工程记录

## P1 结构化抽取约束

- 系统提示明确要求只输出合法 JSON，配合 `response_format={"type":"json_object"}`。
- 用户提示限制实体类型与三类关系，要求 `source/target` 必须引用知识点名称。
- 每个知识点包含来源片段，服务端再使用 Pydantic 校验；非法 JSON、空响应、截断、429、5xx 和超时最多重试两次。
- 真实问答提示要求只依据给定课件分片和图谱邻居证据，证据不足时明确拒答。

默认模型为 `deepseek-v4-flash`，可通过 `DEEPSEEK_MODEL` 覆盖。官方 JSON Output 要求提示中出现 JSON 并提供目标结构示例，当前实现已经满足。

真实抽取正文上限为 60,000 字符。首次结果少于 20 个知识点或未覆盖 `contains / prerequisite / related` 时，系统执行一次完整补全调用；仍不达标时保留候选版本并显示质量警告，不自动发布。

## 知识点抽取提示词

```text
你是高校课程知识图谱抽取专家。只输出合法 JSON，不要输出 Markdown。
从课程原文抽取 20 至 30 个有教学价值的知识点，类型限定为
chapter/concept/skill/formula/example/project。每个节点必须给出
document_id、filename、page_no、原文 excerpt、confidence 和 reason。
excerpt 必须直接来自原文，重复概念按标准名称合并。
```

## 关系识别提示词

```text
请基于课程原文识别关系，关系类型只能从 contains、prerequisite、related 中选择，
且三类必须覆盖。source/target 必须引用已输出知识点名称；每条关系也要给出来源、
页码、原文片段、置信度和判断理由。
```

## RAG 问答提示词

```text
你是课程助教。只能依据编号证据回答；证据不足时明确说不知道。
引用必须使用 [1][2] 格式，不得引用未提供的材料，也不得用模型记忆补充课程外事实。
```

## 练习生成提示词

```text
只依据编号课程证据，为薄弱知识点生成基础题、应用题和易错题各一道。
输出 JSON，包含题型、难度、题目、答案、解析和 evidence_ids。
```
