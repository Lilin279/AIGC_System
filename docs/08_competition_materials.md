# 竞赛材料与评分点映射

## 提交材料清单

- 项目概要介绍：见 README 和 `docs/06_solution_design.md`。
- 项目简介 PPT：可基于本文档目录整理。
- 项目详细方案：见 `docs/01` 至 `docs/10`。
- 演示视频：按 README 演示流程录制。
- 系统使用说明：见 `docs/user-guide.md`。
- 提示词工程记录：见 `docs/prompt-engineering.md`。
- 知识抽取准确率测试报告：见 `docs/test-report-template.md`。
- 智能问答测试集与结果：见 `docs/test-report-template.md`。
- 图谱构建示例：使用 `sample_data/documents/` 和前端截图。

## 服务外包竞赛要点映射

- 目标与思路：目标分析、核心流程、演示剧本。
- 问题分析：行业背景、用户需求、痛点和业务流程。
- 解决方案：AIGC 抽取、知识图谱、GraphRAG、路径推荐。
- 实现方案：四层架构、模块清单、接口和成本可行性。
- 风险控制：API、抽取准确率、部署和演示风险。
- 团队管理：后续可按成员分工补充项目排期。
- 商业模式：商业模式画布和 SWOT。
- 创新点：AIGC + 图谱 + 可解释学习导航。
