# 相关先进技术

## AIGC 知识抽取

使用提示词约束大模型输出结构化 JSON，包含知识点名称、类型、定义、示例、来源片段和关系类型。第一版以规则 + Mock LLM 演示流程。

## GraphRAG

问答时先检索课程知识图谱中的相关节点和文档片段，再交给大模型组织回答，并返回引用，避免脱离课程范围。

## 知识融合与消歧

后续可对同义词、简称和重复概念进行归并，例如“函数”“自定义函数”“方法”在不同章节中的关系梳理。

## 图遍历推荐

基于“前置关系”判断某知识点是否已满足学习条件，并按可解锁后续知识数量排序，形成可解释推荐。

## 提示词工程

对抽取、关系识别、问答和练习生成分别维护提示词模板，配套测试集记录输出质量。
