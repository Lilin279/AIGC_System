# 解决方案设计

## 总体架构

系统采用前后端分离架构。前端提供教师端和学生端工作台，后端提供统一 API，数据层第一版使用 JSON 存储，后续可替换为 Neo4j。

## 核心流程

课程资料上传 -> 文档解析 -> 知识点抽取 -> 关系构建 -> 图谱可视化 -> 教师修正 -> 学生学习 -> 路径推荐 / 智能问答。

## 模块职责

- 文档解析模块：识别 TXT / Markdown，清洗段落和章节。
- 知识抽取模块：生成知识点实体和三类关系。
- 图谱管理模块：保存、查询、增删改节点和关系。
- 可视化模块：图谱渲染、节点点击、路径高亮。
- 学习推荐模块：根据前置关系和掌握状态输出下一步建议。
- 智能问答模块：基于图谱节点生成回答并返回引用。

## 数据流

上传文档保存为 DocumentInfo，解析文本进入抽取模块，抽取结果写入 KnowledgeGraph，前端通过 API 拉取图谱并渲染。
