# 项目简介 PPT 大纲

1. 封面：CourseGraph AI 课程知识图谱教学平台、赛题名称、学校与团队。
2. 行业痛点：教师构图成本、学生路径不清、通用问答幻觉、课程资料孤岛。
3. 用户与场景：管理员、主教师、协作教师、学生的完整教学班闭环。
4. 解决方案：课程内容、教学班级、师生关系三层模型与总体架构图。
5. 教师流程：上传课件、真实 AI 抽取、候选差异、审核发布、删除回滚。
6. 学生流程：图谱导航、掌握状态、确定性路径、AI 讲解与三类练习。
7. 主创新：中文 BM25、知识点匹配、图谱邻居扩展组成可溯源 GraphRAG。
8. 可解释性：回答对应课件名、页码、原文片段、知识点、关系和置信提示。
9. 客户化能力：教师审核、班级隔离、批量导入、工单、审计和个人中心。
10. 技术亮点：DeepSeek JSON Output、Pydantic 校验、SQLite FTS5、OCR、Neo4j 降级。
11. 实测结果：实体/关系/来源准确率，抽取与问答 P50/P95，Token 和费用。
12. 商业价值：单校试点、SaaS/私有化路径、数据安全和扩展路线。
13. 团队分工与排期：按真实成员补充。
14. 总结：低门槛构图、可信问答、个性化学习的教学闭环。

第 11 页必须使用真实 Key 和人工标注结果，不填写模拟成绩。
