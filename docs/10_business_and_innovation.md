# 商业模式与创新点

## 商业模式画布

- 客户细分：高校教师、课程建设团队、教务数字化部门、在线教育平台。
- 价值主张：降低知识图谱构建成本，提升学生个性化学习体验。
- 渠道：高校试点、产教融合项目、竞赛成果转化。
- 收入来源：SaaS 订阅、私有化部署、课程资源建设服务。
- 关键资源：AIGC 抽取能力、课程知识图谱模板、教学数据。

## SWOT

- 优势：赛题贴合教育数字化，原型闭环完整。
- 劣势：第一版真实抽取准确率依赖后续 API 接入。
- 机会：高校课程建设和 AI 助教需求增长。
- 威胁：通用大模型平台可能直接提供类似功能。

## 创新点

- 将 AIGC 抽取和教师修正结合，兼顾效率与质量。
- 用图谱前置关系生成可解释学习路径。
- 以课程图谱作为 RAG 问答边界，减少幻觉。
- 文档、原型和测试模板同步交付，符合竞赛闭环。
