# 实现方案

## 四层架构

- 硬件层：普通 Windows / macOS / Linux 电脑，无需 GPU。
- 数据层：课程、文档、节点、关系、问答引用和推荐结果；第一版 JSON，后续 Neo4j。
- 算法层：文本清洗、Mock LLM 抽取、前置关系图遍历、离线 RAG 问答。
- 应用层：React 教师端、React 学生端、FastAPI 接口文档。

## 开发步骤

1. 搭建后端模型、存储和 API。
2. 准备两门课程示例数据和文档。
3. 搭建前端工作台和 G6 图谱。
4. 完成教师上传、抽取、修正演示。
5. 完成学生掌握标记、路径推荐和问答。
6. 补齐竞赛文档和测试模板。

## 成本与可行性

第一版使用开源框架和本地存储，无服务器成本。真实部署时主要成本来自大模型 API、云主机和图数据库服务。
