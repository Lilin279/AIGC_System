# 目标分析

## 功能性目标

- 支持多课程管理，至少维护两门独立课程。
- 支持 TXT / Markdown 上传与解析。
- 支持知识图谱浏览、节点详情、教师修正、学生掌握标记。
- 支持学习路径推荐和智能问答。

## 任务性目标

- 单次抽取生成不少于 20 个知识点。
- 关系类型不少于 3 类：包含关系、前置关系、相关关系。
- 问答返回引用知识点，体现 RAG 思路。
- 路径推荐基于前置关系图遍历，结果可解释。

## 辅助型目标

- 结构清晰，前后端分离，便于后续扩展真实 LLM 和 Neo4j。
- 普通 Windows 电脑可运行。
- 文档覆盖竞赛前置材料。

## 指标设计

- 定量：知识点数、关系数、响应时间、问答测试通过率、抽取抽样准确率。
- 定性：界面易用性、业务流程完整性、方案先进性、竞赛展示表达。
