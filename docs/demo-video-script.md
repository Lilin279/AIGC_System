# 3–5 分钟演示视频脚本

## 0:00–0:25 问题与方案

说明教师手工构图成本高、学生缺少路径、通用问答不可溯源。展示系统登录页和三类角色。

## 0:25–1:40 教师闭环

教师登录，选择课程并上传《第二章 程序语言的基本知识.pdf》。指出页面上的 DeepSeek 在线状态。启动抽取，展示解析、抽取、融合、待审核进度；打开候选版本，说明 20 个知识点、三类关系、页码与原文来源。确认应用后展示图谱。删除一份测试课件，展示影响预览和选择性回滚。

## 1:40–2:35 学生闭环

学生登录，只展示所在教学班。点击图谱节点、标记掌握状态，生成由前置关系确定的学习路径。展示 DeepSeek 对路径的个性化解释，再生成基础题、应用题和易错题。

## 2:35–3:25 可溯源 GraphRAG

提问一个课程内问题，展开回答证据：课件名、页码、原文片段、知识点和图谱邻居。再提问一个课程外问题，展示系统明确拒答。说明检索采用中文 FTS5/BM25，不依赖昂贵向量服务。

## 3:25–4:10 管理与可信性

管理员展示教师审核、班级与用户、批量导入、工单和审计日志。展示 AI 调用台账中的 Token 与耗时，不出现 Key 或课件正文。

## 4:10–4:40 结果与总结

展示真实准确率、抽取耗时、问答耗时和成本表，最后总结“教师审核的图谱构建、证据约束的可信问答、确定性路径上的个性化 AI”。

录制前必须删除测试账号隐私，隐藏 `.env`，并确保画面中的指标来自真实测试。
