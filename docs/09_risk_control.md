# 风险控制

| 风险 | 级别 | 原因 | 监测方法 | 控制手段 |
| --- | --- | --- | --- | --- |
| 大模型 API 不稳定 | 高 | 网络、额度、响应慢 | 记录接口耗时和失败率 | 保留离线 Mock 流程 |
| 抽取准确率不足 | 高 | 课程文本复杂、提示词不稳定 | 人工抽样验证 | 教师修正、提示词迭代 |
| 图谱过密影响展示 | 中 | 节点和关系过多 | 前端截图检查 | 分章节过滤、路径高亮 |
| 部署环境差异 | 中 | Windows 执行策略、依赖版本 | 启动脚本和文档检查 | 使用 npm.cmd、虚拟环境 |
| 演示数据版权 | 中 | 使用公开教材不当 | 资料来源审查 | 默认使用自编示例 |

## 过程记录建议

每轮测试记录日期、责任人、风险项、现象、处理方式和结果，用于形成比赛过程材料。
