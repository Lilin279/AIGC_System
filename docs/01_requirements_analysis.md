# 需求调研分析

## 行业背景

高校课程资源通常以教材、PPT、教案、习题等非结构化文档存在，知识点分散且关系不清。知识图谱能够用节点和关系呈现课程结构，AIGC 能降低抽取和构图成本，RAG 能提升课程问答的可控性。

## 用户角色

- 教师：上传资料、生成课程知识图谱、修正节点和关系、复核抽取质量。
- 学生：浏览图谱、查看知识点详情、标记掌握状态、获取学习路径、进行课程问答。
- 竞赛评委：关注技术可行性、工程完整性、指标可测性、展示闭环和创新价值。

## 业务场景

1. 教师将课程章节资料上传系统。
2. 系统解析 TXT / Markdown，抽取知识点和包含、前置、相关关系。
3. 教师在图谱界面预览并手动修正。
4. 学生基于图谱学习，标记已掌握内容。
5. 系统根据前置关系推荐下一步学习内容。
6. 学生提问，系统基于图谱返回回答与引用。

## 用户期望

教师希望减少手工整理成本，学生希望学习路径更清晰，团队需要一个可运行、可演示、可解释、可扩展的比赛原型。
