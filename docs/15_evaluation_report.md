# CourseGraph AI 系统测试与性能评估报告

评测日期：2026-09-20

## 1. 评测范围与口径

本轮使用项目内两门示例课程完成工程验证，覆盖知识抽取、问答、检索消融、推荐路径和只读接口性能。所有结果均由仓库内脚本生成并保存在 `docs/results/`。

- 知识抽取：2 份课程资料，示例图谱作为银标，共 40 个实体、40 条关系。
- 问答：24 题，其中 20 题为课内问题、4 题为课程范围外问题。
- 检索消融：20 条人工构造的中文改写问题，目标为知识点节点。
- 推荐路径：8 个学习状态，对照人工指定的下一知识点。
- 性能测试：本机开发环境，健康检查和课程图谱只读接口各 60 次请求，并发度 1、5、10。

这些数据可用于工程验收和 PPT 展示，但样本规模较小，不代表真实学校部署容量或正式教学效果。

功能回归方面，后端自动化测试为 34/34 通过（另含 4 个子测试），前端生产构建通过；现有非阻断项为 FastAPI 生命周期接口弃用提示和前端主包体积警告。

## 2. 知识抽取准确率

| 方法 | 实体 Precision | 实体 Recall | 实体 F1 | 关系 Precision | 关系 Recall | 关系 F1 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 离线规则抽取 | 37.50% | 45.00% | 40.91% | 4.90% | 12.50% | 7.04% |
| DeepSeek 结构化抽取 | 75.61% | 77.50% | 76.54% | 27.91% | 30.00% | 28.92% |

DeepSeek 相比离线规则基线，实体 F1 提升 35.63 个百分点，关系 F1 提升 21.88 个百分点。抽取结果的来源字段完整率为 100%，但这只表示来源字段已填写，不等同于引用内容全部正确。

在线 DeepSeek 对单门课程的平均抽取耗时为 8.538 秒。当前关系抽取 F1 明显低于实体抽取，是下一轮最需要优化的算法指标。

## 3. 问答效果

| 指标 | 结果 |
| --- | ---: |
| 课内答案关键词准确率 | 95.00%（19/20） |
| 24 题综合通过率 | 79.17%（19/24） |
| 课程范围识别率 | 100%（4/4） |
| 严格拒答准确率 | 0%（0/4） |
| 预期课件来源 Recall@5 | 60.00% |
| 预期课件来源 MRR | 0.6000 |
| 端到端平均响应时间 | 16.018 秒 |
| 端到端 P95 响应时间 | 17.096 秒 |

四个范围外问题中，模型都能说明“课程资料没有相关证据”，但随后仍然输出了较长的模型常识补充，因此按严格可溯源问答标准判定为拒答失败。这说明当前提示词具备范围识别能力，但缺少生成前的程序化证据阈值门控。

本轮运行服务返回的模式为 `deepseek-graphrag`，未显示 `+hybrid` 或 `+neo4j`，因此上述问答结果不能作为混合检索和 Neo4j 在线链路的最终效果数据。

## 4. 检索消融实验

| 检索方案 | Recall@5 | MRR | Hit@1 |
| --- | ---: | ---: | ---: |
| BM25 | 95.00% | 0.8806 | 80.00% |
| 中文向量检索 | 95.00% | 0.8946 | 85.00% |
| BM25＋向量 | 95.00% | 0.9321 | 90.00% |
| BM25＋向量＋图谱扩展 | 100% | 0.9375 | 90.00% |

与纯 BM25 相比，加入中文向量后 MRR 提升 5.15 个百分点，Hit@1 提升 10 个百分点；继续加入图谱扩展后 Recall@5 从 95% 提升到 100%，MRR 总提升 5.69 个百分点。

本轮消融使用真实 `BAAI/bge-small-zh-v1.5` 向量模型，但未下载并运行完整 Cross-Encoder 权重，因此不能宣称已经验证 Reranker 的实际提升。

## 5. 推荐路径有效性

| 指标 | 结果 |
| --- | ---: |
| 人工下一知识点 Hit@6 | 100% |
| 人工下一知识点 MRR | 0.4500 |
| 前置约束满足率 | 100% |

结果表明规则推荐不会违反已定义的前置约束，人工期望知识点也都能进入前六名；但 MRR 仅为 0.45，说明正确知识点经常不是第一推荐，现有硬编码优先级仍需引入掌握度、难度、学习目标和语义相关性进行重排。

## 6. 系统响应时间与并发能力

课程图谱只读接口测试结果：

| 并发度 | 成功率 | 吞吐量 | 平均延迟 | P95 延迟 |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 100% | 68.95 req/s | 14.47 ms | 31.42 ms |
| 5 | 100% | 81.52 req/s | 58.87 ms | 132.74 ms |
| 10 | 100% | 69.13 req/s | 143.37 ms | 352.70 ms |

在本机 10 并发、60 次请求的小规模测试中未出现接口错误。图谱读取本身维持毫秒级响应，但 DeepSeek 问答受外部模型调用影响，平均需要约 16 秒，两者需要分别展示，不能把健康检查或静态接口的吞吐量当成 AI 问答吞吐量。

## 7. PPT 可直接使用的结论

> 项目建立了覆盖“知识抽取—混合检索—学习路径—系统性能”的可复现评测体系。在两门示例课程银标集上，DeepSeek 实体抽取 F1 达到 76.54%，相比离线规则基线提升 35.63 个百分点；20 条语义改写问题的消融实验显示，BM25、中文向量和图谱扩展融合后 Recall@5 由 95% 提升到 100%，MRR 由 0.8806 提升到 0.9375。推荐路径前置约束满足率和人工目标 Hit@6 均为 100%。本机 10 并发下课程图谱接口成功率为 100%，P95 延迟为 352.70 ms。当前短板是关系抽取 F1 仅 28.92%、严格拒答准确率为 0%，以及大模型问答平均耗时约 16 秒，下一步将重点加入证据阈值拒答、关系抽取约束和 Cross-Encoder 实模型消融。

## 8. 不能夸大的部分

- 抽取参考图谱是项目示例银标，不是独立专家双人标注金标准。
- 尚未进行真实学生对照实验，不能宣称提升学习成绩或教学效率。
- 尚未完成 Cross-Encoder 实模型消融和 Token 成本统计。
- 当前并发测试是本机短时小样本结果，不是生产容量承诺。
- 尚未与商业竞品在同一数据集、同一硬件环境下进行公平对比。
